# NexxaTech — Mini Project Full Stack Web Development

NexxaTech adalah contoh **landing page marketplace produk digital**. Website ini menampilkan kategori dan beberapa contoh produk digital dengan desain bertema gelap (*dark theme*).

Project ini dibuat untuk Mini Project **HTML, CSS & Tailwind** pada Bootcamp Full Stack Web Development Batch 13 di Dibimbing.

## Assignment 1 — HTML & CSS

**Status: selesai.**

Halaman utama dibuat menggunakan HTML dan CSS, dengan bagian-bagian berikut:

- Navbar dan Hero Section
- Categories: E-books, Templates, Source Code, UI Kits, dan Digital Media
- Featured Product: Social Media Template Pack
- Trending: empat contoh produk digital
- Footer dan tautan sosial media

Tampilan disesuaikan untuk **desktop, tablet, dan mobile** menggunakan CSS Flexbox, Grid, serta media query.

## Assignment 2 — Tailwind CSS



Rencana halaman: katalog produk (*Product Catalog*) menggunakan Tailwind CSS. Bagian ini akan diperbarui setelah Assignment 2 selesai.

## Teknologi

- HTML5
- CSS3 (Flexbox, Grid, dan Media Query)
- Google Fonts — Space Grotesk
- Tailwind CSS
